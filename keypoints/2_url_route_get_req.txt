#1  what is API?
    API is a bridge b/w frontend & backend
    frontend sends request & backend returns response
    mostly in json format

#2  what are routes?
    routes are URL path, at which specific function can be executed based on
    the path

#3  why only json format?
    - main purpose of API is data exchange
    - json is light weight, easy to use format for frontend

#4  what is Swagger UI?
    autogenerated API doc tool
    where we can test API without postman
